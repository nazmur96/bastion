# Kubernetes tool integrations — options (to decide)

Researched 2026-11-01. For the DevOps IDE spec (B1 Kubernetes panel and beyond).

| Tool                                        | What it is                                                                                                                                                                                           | Fit for the IDE                                                                                                                                      |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Radar** (skyhook-io/radar, open source)   | Kubernetes UI run against your kubeconfig, nothing installed in the cluster: live topology graph, timeline, Helm rollback, GitOps view, eBPF traffic map, audit, **built-in MCP server for Claude**. | Strongest candidate for B1: embed Radar's local UI in Orca's browser pane per workspace instead of building a panel, and give Claude its MCP server. |
| **vind** (loft-sh/vind, vCluster in Docker) | KinD replacement: full clusters as Docker containers, sleep/wake, LoadBalancer services, built-in UI.                                                                                                | One-click "local cluster" Toolbelt actions (create / sleep / wake / delete) for practice; runs on Podman via Docker API.                             |
| **vCluster**                                | Virtual clusters inside a host cluster.                                                                                                                                                              | Per-workspace throwaway cluster on EKS later (cheaper than one EKS per test).                                                                        |
| **Tilt**                                    | Tiltfile-driven inner loop, live update, web UI. In maintenance mode since Docker acquired it.                                                                                                       | Toolbelt "tilt up" + open its UI in the browser pane when a Tiltfile exists (podinfo has one). Don't build on it long term.                          |
| **Skaffold**                                | Client-side build/push/deploy loop, no cluster component.                                                                                                                                            | Toolbelt actions when `skaffold.yaml` exists.                                                                                                        |
| **Okteto**                                  | Syncs local code into a dev pod on a remote cluster.                                                                                                                                                 | Detect `okteto.yml`; actions `okteto up/down`. Needs a cluster.                                                                                      |
| Lens / Headlamp                             | Desktop / web K8s UIs (old Dashboard archived Jan 2026).                                                                                                                                             | Headlamp is an alternative to Radar for embedding.                                                                                                   |

Pattern: detect the tool's config file → Toolbelt actions → if it has a web UI, open it in Orca's browser pane next to the chat → if it has an MCP server, give it to Claude.

## Local cloud

| **Floci** (floci.io, MIT, no sign-up) | Local emulators for AWS (126 services: S3, SQS, Lambda, DynamoDB, RDS…), Azure, GCP, OCI; containers on Docker/Podman; `eval $(floci env)` points `aws`/`terraform` at it; optional dashboard. | "Local AWS" Toolbelt mode: start Floci, inject its env into the workspace's terminals and Claude's commands; context bar shows "AWS: floci (local)" in green; the safety gate (A2) skips approvals for this unbilled context; dashboard in the browser pane. Check service fidelity (EKS, IAM) before relying on it per template phase. |
